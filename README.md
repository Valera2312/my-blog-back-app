# Бекенд для приложения "Блог"

Приложение "Блог" предоставляет пользователям возможность создавать, редактировать и просматривать статьи, комменировать, ставить лайки
Этот документ описывает структуру и функциональность бекенда приложения.
## Технологии
- Язык программирования: Java 21
- Фреймворк: Spring 7 (JDBC, WebMvc, Context, Test)
- База данных: PostgreSQL
- Система сборки: Gradle 9.0.0
- Инструменты тестирования: JUnit 5, Mockito, Spring TestContext Framework
## Структура проекта
```
blog-backend/
├── src/main/                   # Основной исходный код приложения
    ├──webapp/                  # Конфигурация веб-приложения standalone
│   │   └── WEB-INF/web.xml      # Файл конфигурации веб-приложения
│   ├── java/ru/valera/         # Пакет с исходным кодом
│   │   ├── application/        # Слой приложения Use Cases (сервисы, мапперы, DTO)
│   │   ├── domen  /            # Домен (сущности и бизнес-логика)
│   │   ├── infastructure/      # Слой инфраструктуры (репозитории, конфигурации, достум к файловой системе
│   │   └── presentation/       # Слой представления (контроллеры, обработчики експешенов)
│   └── resources/
│       ├── application.properties  # Конфигурационный файл приложения
│       └── blog_init.sql           # Скрипт инициализации базы данных       
├── src/test/                   #  Тесты 
│   └── java        # Пакет с тестами
│       └──PostControllerIntegration.java  # Интеграционные тесты
└── build.gradle.kts               # Файл сборки Gradle
```
## Основные функции
- Управление статьями: создание, редактирование, удаление и просмотр статей.
- Комментирование: добавление, редактирование и удаление комментариев к статьям.
- Лайки: возможность ставить и снимать лайки с статей и комментариев.
- Изображения: загрузка и отображение изображений для статей.
- Пагинация: поддержка пагинации для списков статей.

## Запуск приложения
1. Убедитесь, что у вас установлены Java 21, PostgreSQL.
2. Настройте базу данных PostgreSQL, создав новую базу данных и пользователя.
3. Обновите файл `application.properties` с вашими настройками базы данных.
4. Выполните команду сборки war: `./gradlew build`.
5. Разверните сгенерированный файл WAR в вашем контейнере сервлетов (например, Apache Tomcat).
6. Запустите контейнер сервлетов и откройте приложение в браузере по адресу `http://localhost:8080`.
## Тестирование
Для тест контейнеров неободимо установить Docker
Убедитесь, что Docker установлен и запущен на вашем компьютере.
Для запуска тестов выполните команду:
` ./gradlew test `
Это запустит все интеграционные тесты, обеспечивая проверку функциональности приложения.
